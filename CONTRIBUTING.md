# Contributing

Keep neural outputs and engineered pet rules distinct in code and documentation.
Preserve upstream copyright and dataset licensing. Do not add telemetry, broad
permissions, autostart or remote services without an explicit user-facing design.

Build with `./build.sh`; run the five check commands in README. New life-cycle
or feeding behavior should include meaningful transition and timing checks.
UI changes should also be exercised in the native macOS app.
